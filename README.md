# Windows AI 智能文档知识库客户端（MVP + 桌面版）

基于 PRD《Windows AI智能文档知识库客户端》实现的本地私有 AI 文档知识库。
**全部数据（原始文件、向量库、行为数据）本地存储，不上传任何原始文件。**

## 桌面版（打包落地 · 推荐普通用户使用）

已打包为 **Windows 桌面应用**（PyInstaller，双击即用、无控制台黑窗口），产物：

```
dist/AI文档知识库/
├── AI文档知识库.exe        # 双击启动，弹出原生桌面窗口（非浏览器）
├── _internal/              # 运行时依赖（勿删）
└── data/                   # 数据目录（可整体备份/迁移）
    ├── knowledge.db        # 知识库元数据
    ├── uploads/            # 手动上传原件（本地存储）
    ├── models/             # Embedding 模型（本地向量化）
    └── logs/desktop.log    # 运行日志
```

- **使用**：双击 `AI文档知识库.exe` → 自动启动本地服务并弹出**原生桌面窗口**（pywebview + WebView2，非浏览器标签页）→ 即开即用
- **开箱即用**：Embedding 模型已内置（全程本地向量化）；AI 问答在「设置」页填写 API 地址/密钥/模型后使用
- **数据位置**：所有数据在 exe 同目录 `data/`，删除整个文件夹即彻底清除隐私数据；换机拷贝整个 `AI文档知识库/` 文件夹即可迁移
- **端口冲突**：8000 被占用时自动顺延 8001/8002…
- **日志**：无控制台界面，运行日志写入 `data/logs/desktop.log`；启动失败会弹窗提示
- **系统要求**：Windows 10/11，需 WebView2 Runtime（Win11 自带；Win10 通常已随系统更新安装）

## 页面导览

- **首页**：知识库统计、最佳文档 TOP10（六维权重）、最近新增
- **添加文档**（V2.1 优化）：
  - 「＋ 选择文档」→ 打开本地文件资源管理器，多选文档直接入库（PDF/DOCX/DOC/XLSX/PPTX/TXT/MD）
  - **拖拽上传**：把文档拖进页面任意位置即可入库
  - 「扫描目录」→ 批量扫描整个文件夹，勾选确认后入库（含后台静默扫描提醒）
- **文档库**：分类侧栏、标签筛选、关键词搜索、批量删除、编辑（重命名/改分类/打标签）
- **AI 问答**：对话式提问 → 溯源答案（文档名+命中片段）→ 点赞/点踩 → 右侧动态相关文档推荐
- **设置**：API 配置（地址/密钥/模型）、监控目录、忽略规则、一键清空

## AI 配置（设置页填写）

在 **设置 → AI 问答服务** 中填写兼容 OpenAI 的 API 地址、密钥与模型名称即可使用，密钥仅保存在本机。

隐私规则：文档解析/切片/向量化全部本地完成，**原始文件绝不出本机**；调用云端 API 时只把检索命中的少量片段发给服务端。

## API 密钥配置（.env）

设置页保存的配置优先；未保存时使用 `.env` 中的默认值（**不写入代码**），修改后重启软件生效，无需重新打包：

| 运行方式 | .env 位置 |
|---|---|
| 开发模式 | 项目根目录 `.env` |
| 桌面版 exe | exe 同目录 `.env` |

支持变量：

- `AIWJ_API_BASE` / `AIWJ_API_KEY` / `AIWJ_MODEL`：设置页未保存时的默认值

优先级：设置页保存值 > 系统环境变量 > `.env` 文件 > 代码默认值。密钥仅存于 `.env` / 本地数据库，更换密钥直接在设置页修改即可。

## 项目结构

```
aiwenjian/
├── run.py                  # 启动入口
├── requirements.txt
├── backend/
│   ├── config.py           # 全局配置（切片规则/分类体系/阈值）
│   ├── db.py               # SQLite：文档/行为/切片/设置/任务
│   ├── scanner.py          # 目录扫描 + MD5 去重 + 忽略规则
│   ├── parser.py           # 文档解析（pdf/docx/xlsx/pptx/txt/md/doc）
│   ├── chunker.py          # 智能切片（256/512/768 自适应）
│   ├── embedder.py         # bge-small-zh-v1.5 本地向量化（ONNX）
│   ├── vector_store.py     # Chroma 持久化向量库
│   ├── retriever.py        # BM25+向量 混合检索 + 行为权重
│   ├── classifier.py       # AI 分类 + 个性化学习
│   ├── rag.py              # RAG 溯源问答（防幻觉）
│   ├── recommender.py      # 六维权重最佳文档推荐
│   ├── llm.py              # 大模型推理（设置页 API 配置）
│   ├── pipeline.py         # 入库流水线（异步任务）
│   └── api.py              # FastAPI 路由
├── frontend/               # 原生 HTML/CSS/JS 单页应用
│   └── js/                 # 前端模块（utils/任务/通知/首页/文档库/上传/扫描/文档弹窗/问答/设置/入口）
├── tests/smoke_test.py     # 端到端冒烟测试
└── data/                   # 运行时数据（本地存储）
    ├── chroma/             # 向量库
    ├── knowledge.db        # 元数据
    ├── uploads/            # 手动上传原件
    └── models/             # Embedding 模型缓存
```

## V2.0 已上线

### 1. 本地离线 Embedding（全程本地向量化）

- Embedding 模型（bge-small-zh-v1.5，约 95MB）内置，文档解析/切片/向量化全部本机完成，**原始文件绝不出本机**
- 说明：Embedding 模型缺失时检索自动降级为关键词模式，模型就绪后自动启用语义检索

### 2. API 在线模式（设置页自定义配置）

在 **设置 → AI 问答服务** 中填写 API 地址、密钥与模型名称并保存即可，无需改动代码或环境变量。密钥保存在本机，隐私规则不变：仅检索片段上传，原始文件不出本机。

### 3. 进入即扫描 + 新文档提醒

- 每次进入软件自动扫描一次监控目录（设置页可配置，也可点「立即扫描一次」手动触发）
- 发现新文件 → 侧边栏「新文档提醒」红色徽标 + 确认入库弹窗
- 隐私规则：**只提醒、不静默入库**；MD5 全局去重、10s 写入稳定保护

## 二期预留（V2.5+）

- 完整个性化学习闭环调优（分类/检索/问答权重微调）
- 扫描件 OCR（PaddleOCR 可选组件，`parser.py` 已预留接口）

## 已知限制

- `.doc` 旧格式为尽力提取（OLE 文本流），建议另存为 `.docx`
- 扫描件 PDF 需安装 PaddleOCR 可选组件（约 1GB，低配机不建议）
- 本地 3B 模型问答质量弱于云端大模型，但对合同条款/会议纪要等知识库事实问答足够
- 当前 `data/` 内含冒烟测试演示文档，可在「设置 → 一键清空」后开始真实使用
